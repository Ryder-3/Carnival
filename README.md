# Carnival
A Cryptid Addon (for now) that focuses on adding more progression and little mini games into Balatro

# Installation
* Make sure you have the most recent version of [Steamodded](https://github.com/Steamodded/smods) installed
* Make sure you have the most recent version of [Cryptid](https://github.com/SpectralPack/Cryptid) installed
* Download the Carnival folder from this repo
* Extract the folder
* Drag and drop the folder into your game's "mods" folder
